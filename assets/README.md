# Profile artwork

The profile uses the portfolio's Route Board identity: maroon `#7a1712`, chalk `#edefea`, ink `#141210`, and signal yellow `#ffc20e`. Header lettering is outlined Archivo, so it renders consistently without a remote font request. The Archivo license is in `fonts-OFL.txt`.

- `header.svg` and `header-mobile.svg`: custom vector artwork, a short route animation, and reduced-motion support.
- `footer.svg`: matching vector signature.
- `snapvyn.webp` and `menuvyn.webp`: real product captures copied from the portfolio's `public/work/`, captured 2026-10-16. Sources: [Snapvyn](https://www.snapvyn.com) and [Menuvyn](https://www.menuvyn.com).
- `activity*.svg`: generated by `node scripts/update-activity.mjs`. Desktop/mobile compositions and light/dark palettes use GitHub-supported `<picture>` markup.

## Activity updates

The workflow runs daily at 02:35 UTC (08:05 in Sri Lanka), on manual dispatch, and when its source changes on `main`. It uses the built-in `GITHUB_TOKEN`; no personal access token or extra secret is needed. GitHub may delay scheduled runs and disables schedules on inactive public repositories after 60 days.

Initial artwork is generated locally from public GitHub data. In Actions, the script reads GitHub's contribution GraphQL API. Local runs without a token use the public calendar; if its markup changes, the script fails and retains the existing artwork. Counts include anonymized private contributions if the owner has made those counts public. Repository/follower counts are public profile data. The widget is a daily snapshot. Failed requests never replace working artwork with error images.

Refresh with Node 24 or later:

```sh
node scripts/update-activity.mjs
```

Edit the root `README.md` for profile content. Product descriptions, contact details, links, and palette came from the portfolio's `src/content/` and `DESIGN.md`.

The optional `scripts/build-artwork.cjs` authoring tool uses `fontkit` and the portfolio's two Archivo TTF files. It produces the committed SVGs; neither the font files nor this dependency are needed to display the README or run daily updates. Display lettering is Archivo; the data graphic uses a standard sans-serif for portable SVG text.

## Features researched

- [Responsive and theme-aware images](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github): used for header and activity artwork.
- [Collapsed sections](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/organizing-information-with-collapsed-sections): native project/process disclosures.
- [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats): the original recommends maintained successors. [GitHub Readme Stats Action](https://github.com/stats-organization/github-readme-stats-action) is an alternative for standard cards.
- [Metrics](https://github.com/lowlighter/metrics) and [contribution snake](https://github.com/Platane/snk): explored as alternatives. This profile uses custom activity artwork matching the portfolio.

All public-facing media is stored here. There are no visitor trackers or third-party image endpoint dependencies.
